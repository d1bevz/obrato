# Obrato

**AI-ассистент прораба.** Web-PWA (таргет — Android-телефон прораба, D1), которое из
замеров помещения и состава работ детерминированно считает количества материалов по
нормам расхода, собирает локализованный список закупок (Leroy Merlin Portugal +
локальные магазины Лиссабона) с ценами-ориентирами и разбивкой по этапам стройки,
и строит редактируемые 2D-чертежи (план полов, раскладка плитки, точки электрики).

## Зачем

Прорабы теряют деньги из-за нехватки нужных материалов в нужный момент: нет
материала → простой → срыв следующего заказа (≈1000 €/день потерь). Корень — нет
времени и горизонта на планирование закупок. Obrato снимает планирование с головы
прораба и переводит замеры в точную смету и план закупок вовремя.

Это инструмент **прораба**, а не дизайнера и не конечного заказчика. Эстетику/дизайн
Obrato не генерирует — он считает, что и когда покупать.

## Код

[`compute-core/`](compute-core/) — **TypeScript-прототип** движка (модель ввода →
нормы → количества → упаковки → лист по этапам), 17 юнит-тестов + курируемый каталог
(141 SKU, 9 магазинов Лиссабона). Это **референс-эталон контракта, НЕ продукт**:
продуктовое ядро пишется на Rust (`crates/compute-core`, гл.03/09, D3), спецификация
формул — гл.07. См. `compute-core/README.md`.
