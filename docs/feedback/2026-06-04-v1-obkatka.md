# Обкатка v1 (P0–P5) — комментарии Димы, triage и статусы

> Процесс: Дима вываливает комментарии в любом виде → Архимед раскладывает
> сюда с категорией и приоритетом → пачки-итерации (каждая заканчивается
> задеплоенным артефактом + ревью) → статус обновляется коммитом.
>
> Деплой первой версии: 2026-06-04, https://72.61.103.206.sslip.io
> (PR #5, merge c575883).

## Категории

- **bug** — сломано/врёт: чинится в первую очередь
- **ux** — непонятно/неудобно: мелочь пачкой, крупное отдельной итерацией
- **norm/data** — нормы, каталог, цены: трек калибровки (гл.11), не код
- **design** — меняет дизайн-решения: сперва правка docs/design, потом код
- **deferred** — фаза 2: паркуется со ссылкой на главу

## Статусы

`new` → `triaged(P0|P1|P2)` → `in-progress` → `done(commit)` / `parked(ссылка)`
